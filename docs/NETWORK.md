# 网络传输（SFTP）

状态：引擎与 UI 已实现，主机测试与目标镜像构建通过（AArch64，已链接
`libssh2.so.1`）；**真机连接真实服务器尚未验证**（`NOT RUN`）。

## 用途

不拔卡、不拆机，从同一 Wi-Fi 下的电脑把游戏传到掌机：

```
电脑 (SSH/SFTP 服务器)  ──Wi-Fi──▶  gameOS
                                    下载到 /userdata/network
                                    再用「文件管理」移进 roms/<平台>/
```

下载完成后不会自动导入游戏库；进入设置 → 文件管理，把文件移动或复制到对应
平台的 `roms/` 目录即可。

## 使用步骤

1. 在电脑上启用 SSH/SFTP 服务器（Linux 的 `openssh-server`；Windows 10/11 的
   「可选功能 → OpenSSH 服务器」）。
2. 掌机：设置 → 网络传输，填写：

   | 字段 | 说明 |
   |------|------|
   | 服务器 | IP 或主机名，例如 `192.168.1.10` |
   | 端口 | 默认 `22` |
   | 用户名 | 电脑上的账号 |
   | 密码 | 只用于本次运行，不保存、不写日志 |
   | 远端目录 | 绝对路径，例如 `/home/me/roms`；Windows OpenSSH 写作 `/C:/Users/me/roms` |

3. 选「连接」登录，浏览目录：轻触文件夹进入，轻触文件下载；也可以点「上一级」。
   如果登录失败或连接失败，状态栏会显示原因。
4. 下载显示进度、速度与剩余时间，可随时取消。失败或取消后可以「重试」，服务器
   支持时从 `.part` 断点续传，不会从头再来。
5. 下载完成后到文件管理里把文件移进 `roms/`。重名文件会自动加序号，不覆盖已有文件。

## 安全与边界

- **主机指纹固定（TOFU）**：首次连接会把服务器 SHA256 指纹写入
  `/userdata/system/sftp_known_hosts`；之后指纹不一致立即中止并提示，防止
  中间人冒充。确认服务器重装或换钥后，删除该文件重新信任。
- **密码只在内存**：`/userdata/system/sftp.ini` 只存服务器、端口、用户名与远端
  目录（0600，原子写），不存密码；密码不会写进常规日志。
- **路径限制**：远端路径必须是绝对路径，拒绝 `.`、`..`、控制字符与超长输入；
  本地只取文件名，拒绝目录成分与非法字符，不能借文件名写出目标目录。
- **落盘顺序**：先写 `.part`，校验远端大小与本地字节数完全一致、`fsync` 后再
  rename；取消/失败保留 `.part` 供下次续传。
- **空间预检**：下载前检查 `/userdata/network` 所在分区剩余空间，并预留 8 MiB
  余量；空间不足直接拒绝。
- **并发**：同一时间只有一个传输任务；离开网络页面不影响传输进行，关闭 UI
  会取消并等待工作线程退出。

## 当前范围（未实现）

- 只有 SFTP，且只支持密码登录；SMB / FTP / FTPS、密钥登录、上传、目录递归
  下载、后台常驻传输都不在本版本内。
- 不提供远端删除/改名；远端始终只读。
- 不校验 ROM 内容与扩展名，下载后的文件由用户自行整理。
